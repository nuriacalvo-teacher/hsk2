# Carpeta de audio

Aquí van los audios grabados con voces neuronales chinas, cada uno en tres
versiones:

- `lento/` — velocidad −40 % (la app ofrece además «muy lento», que es esta
  versión reproducida al 80 %)
- `medio/` — velocidad −20 %
- `normal/` — velocidad natural

`manifest.js` / `manifest.json` son el índice: duración de cada audio y el
momento en que empieza cada línea (para poder repetir una frase suelta del
listening).

**Si esta carpeta está vacía no pasa nada**: la app usa la voz china del
navegador. Para grabarlos, mira el README principal.
